
# پروژه تشخیص ژانر موسیقی با پایتون

## 1. معرفی پروژه

هدف این پروژه طراحی یک سیستم هوشمند برای تشخیص ژانر موسیقی است.

در این سیستم فایل‌های صوتی دریافت می‌شوند و در مراحل بعدی با استفاده از روش‌های پردازش صوت و یادگیری ماشین، ژانر موسیقی آن‌ها تشخیص داده خواهد شد.

## 2. گام دوم: ساخت یا جمع‌آوری داده

در این گام، داده‌های موردنیاز پروژه تهیه و برای مراحل بعدی آماده می‌شوند.

## 3. منبع داده

منبع داده مورد استفاده در پروژه، دیتاست GTZAN است.

این دیتاست شامل قطعات موسیقی در ژانرهای مختلف است.

لینک منبع:
https://huggingface.co/datasets/storylinez/gtzan-music-genre-dataset

مجوز استفاده:
مطابق مجوز اعلام‌شده در صفحه نسخه مورد استفاده دیتاست.

## 4. ساختار داده‌ها

فایل‌های صوتی بر اساس ژانر در پوشه‌های جداگانه قرار گرفته‌اند.

ژانرهای مورد استفاده در نسخه آزمایشی:
- Rock
- Jazz
- Classical
- Hiphop
- Blues

## 5. اسکریپت بارگذاری داده

فایل src/load_data.py با زبان پایتون نوشته شده است.

وظایف این اسکریپت:
- شناسایی پوشه‌های ژانر موسیقی
- پیدا کردن فایل‌های صوتی
- ثبت نام فایل‌ها
- ثبت مسیر فایل‌ها
- تعیین ژانر بر اساس نام پوشه
- ذخیره اطلاعات در فایل CSV

## 6. خروجی برنامه

خروجی اسکریپت در مسیر زیر ذخیره می‌شود:

data/processed/metadata.csv

این فایل شامل سه ستون است:
- file_name
- file_path
- genre

## 7. کتابخانه‌های مورد استفاده

- pathlib
- pandas

## 8. نحوه اجرای پروژه

ابتدا محیط مجازی را ایجاد کنید:

python -m venv .venv

سپس محیط را فعال کنید:

.venv\Scripts\activate

کتابخانه‌های موردنیاز را نصب کنید:

python -m pip install -r requirements.txt

در نهایت برنامه را اجرا کنید:

python src/load_data.py

## 9. وضعیت پروژه

اسکریپت بارگذاری و ثبت اطلاعات فایل‌های صوتی پیاده‌سازی شده است.

پاک‌سازی و تقسیم مجموعه داده در مرحله بعد انجام خواهد شد.

## 10. تست و بررسی عملکرد برنامه

برای بررسی صحت عملکرد اسکریپت بارگذاری داده‌ها،
برنامه اجرا شد و فایل‌های صوتی موجود در پوشه‌های
ژانر موسیقی با موفقیت شناسایی شدند.
